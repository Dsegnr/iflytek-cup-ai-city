## 要解决的问题

传统交通信号控制依赖**固定配时方案**，难以适应动态、瞬变的交通流——单一节点的拥堵很容易扩散成区域性的路网效率塌陷。而增建道路受「当斯定律」制约：新的道路供给会诱发新的需求，长期看治标不治本。

本项目把控制粒度下沉到**转向车道**，用「预测 + 强化学习决策」替代固定配时。

## 技术路线

```
多源数据感知  →  随机森林预测  →  Q-Learning 协同决策  →  信号配时输出
```

**1. 数据感知层**
集成实时 API 数据流与边缘计算设备，采集目标转向车道的**平均速度、排队长度、车头时距**等关键参数。

**2. 预测层 —— 优化随机森林**
在短时间内完成海量数据挖掘，输出短时交通状态预测。

**3. 决策层 —— 基于 Q-Learning 的多路口协同控制**
把每个车道视为预测对象，通过预训练阶段**数百万次交互迭代**生成最优 Q 表；实时运行时依据 Q 表动态生成信号灯配时方案。

**关键设计 · 防拥堵转移**
任何针对单一车道的绿灯时长调整，决策函数**内置对关联车道交通状态的影响评价**——避免"这个路口通了、隔壁堵死"的常见副作用。
